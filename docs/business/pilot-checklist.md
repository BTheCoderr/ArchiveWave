# ArchiveWave — First pilot checklist

Use this for each real customer. Do not store completed copies with personal or private details in the public repository.

## Qualification
- [ ] Owner/contact and podcast identified via approved private channel
- [ ] Rights holder and edit authority verified
- [ ] RSS URL and selected episode list confirmed
- [ ] Audio-processing permission recorded
- [ ] Sponsorship obligations and expiration evidence supplied or flagged unknown

## Before work
- [ ] Written scope and price accepted
- [ ] Number of episodes and deliverables agreed
- [ ] Customer-approved secure transfer method selected
- [ ] Originals backed up and checksum/inventory recorded
- [ ] Retention/deletion expectations agreed

## Audit and approval
- [ ] RSS inventory generated
- [ ] Audio transcribed locally with permission
- [ ] Candidate timestamps manually reviewed
- [ ] False positives removed from recommendations
- [ ] Exact edits approved in writing

## Delivery
- [ ] Edit working copies only
- [ ] Check continuity, loudness, and accidental content loss
- [ ] Compare duration and edit log
- [ ] Deliver revised files securely with change log
- [ ] Customer accepts files and controls publication
- [ ] Record actual labor, feedback, and follow-up decision
